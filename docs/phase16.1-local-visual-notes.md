# ملاحظات الفحص البصري المحلي — Phase 16.1

**التاريخ:** 2026-08-25

| المسار | البيئة | النتيجة |
|---|---|---|
| `/` | Chromium sandbox، العرض الافتراضي للأداة | الصفحة ظهرت RTL، والعنوان والمحتوى العام ظهرا، مع حالة آمنة واضحة «تعذر الوصول إلى الكتالوج المنشور الآن» بدل تحميل لا نهائي بسبب غياب DB المحلية. |
| `/register?next=%2Faccount%2Fprofile` | Chromium sandbox، العرض الافتراضي للأداة | نموذج التسجيل ظهر RTL كاملًا مع labels وحقول password وزر إرسال وحالة بدون أخطاء. لم يتم إرسال النموذج. |

لم تتوفر Playwright أو Puppeteer ضمن `node_modules`، ولا توفر أداة المتصفح الحالية تغيير viewport إلى المقاسات الأربعة المطلوبة. لذلك لا تُعد هذه الملاحظات تحققًا خارجيًا للمقاسات 390×844 و393×852 و768×1024 و1440×900؛ هذه المقاسات تبقى NOT TESTED إلا بقدر العرض الافتراضي الظاهر أعلاه. لم تُستخدم جلسة مستخدم ولم تُنفذ أي طلبات mutation.

| `/categories` | Chromium sandbox، العرض الافتراضي للأداة | ظهرت الصفحة RTL مع عنوان وتصميم وحالة آمنة عند عدم توفر الكتالوج المحلي؛ لم تظهر أخطاء عميلة أو تحميل لا نهائي. |
| `/search` | Chromium sandbox، العرض الافتراضي للأداة | ظهر نموذج البحث RTL وحقول الاسم/التصنيف/المدينة/الدولة وزر البحث؛ الحالة الآمنة عند غياب الكتالوج واضحة، ولم يُرسل استعلام mutation. |

| `/login?next=https%3A%2F%2Fevil.example%2F` | Chromium sandbox، العرض الافتراضي للأداة | ظهر نموذج الدخول RTL. فحص DOM أثبت أن رابط التبديل أصبح `/register` دون تمرير وجهة خارجية؛ لم تُرسل بيانات الدخول. |
